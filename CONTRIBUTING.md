# Contributing

## Add a path

Open a PR that:

1. Places the entry under the right section in `README.md`
2. Describes a **minimal rebuild** (not “install this SaaS”)
3. Names a clear done condition
4. Links to legal, high-quality learning material

## Report a rebuilt system

Open an issue titled `I rebuilt X` with:

- What you built
- Language / repo link
- One thing that surprised you

## Do not

- Paste large copyrighted tutorials into this repo
- Add material aimed at unauthorized computer access or harm
- Claim affiliation with other “build your own X” projects
